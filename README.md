# МОРОЗОВКА — лаунчер

Рабочий лаунчер: создание/выбор персонажей, привязка аккаунта, выбор сервера, настройки, установка на телефон как приложение (PWA). Данные хранятся в браузере (localStorage).

## Как выложить на GitHub
1. Создай репозиторий на github.com (New repository), например `morozovka`.
2. Нажми **Add file → Upload files**, перетащи все файлы из этой папки (включая `.nojekyll`), нажми **Commit**.
3. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. Через минуту лаунчер откроется по адресу `https://ТВОЙ_НИК.github.io/morozovka/`.
5. На телефоне открой ссылку в Chrome → меню → **Установить приложение**.

## Как подключить игру
В `index.html` найди `CONFIG` и впиши `url` у серверов: адрес веб-версии твоей игры. Кнопка «Играть» откроет его с параметрами `?nick=...&uid=...`.
